## Installation

{/* Lead with the project's own copy. One subsection covers adding or updating from any registry. */}

`Name` already ships in this project's component library, in the directory chosen when the project
was scaffolded. Import it from the project's namespace:

```tsx
import { Name } from "@workspace/ui/components/name";
```

### Add or update from a registry

The registry is private. Create a registry token at [create.merkle.design/account/tokens](https://create.merkle.design/account/tokens) and export it as `REGISTRY_TOKEN` before you run the command. The registry entry in `components.json` sends it as a Bearer header.

```bash
export REGISTRY_TOKEN="YOUR_REGISTRY_TOKEN"
```

```npm
npx shadcn@latest add @<registry>/<item>
```

`<registry>` is any namespace configured under `registries` in `components.json`. `@focus` is the upstream library and is always configured; this project's own registry is another namespace, once it publishes one. Item names follow each registry's naming: `@focus` prefixes components with `ui-`, but another registry may name the same item `name`, so use the name that registry lists. For example:

```npm
npx shadcn@latest add @focus/ui-name
```

Adding over an existing local component can overwrite local edits, so review the diff first.
