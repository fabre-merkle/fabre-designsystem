## When to use it

Author Storybook stories for your @workspace/ui components to the story standard — one concept per story, JSDoc-driven autodocs, a per-component a11y + interaction + token-load baseline — so the Storybook MCP is a reliable, grounded source of component truth for agents. Use after Storybook is set up. Requires React + Vite Storybook and the Storybook MCP.
