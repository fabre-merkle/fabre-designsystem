## When to use it

Tokens Studio MCP + CLI skill for a scaffolded project. Covers the initial project push (DTCG → Tokens Studio + export setup), token re-pulls, CSS export management, theme edits, and CLI config refresh. Use when working with Tokens Studio in a project generated by the scaffolder. Requires the Tokens Studio MCP (packages/tokens/TOKENS-STUDIO.md → "MCP" section) and the CLI (@tokens-studio/studio-cli, automatically installed on demand by Studio-dependent `tokens:*` scripts).

**Canonical source:** `.agents/skills/skill-tokens-studio/SKILL.md`. Claude Code uses `.claude/skills/skill-tokens-studio/`; other clients use their installed skill paths.
