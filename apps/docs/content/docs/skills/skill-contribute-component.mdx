## When to use it

This skill should be used when authoring a new UI component in a scaffolded project, or changing an existing one — composing it on Base UI, wiring the data-attribute API, writing token-driven CSS in the correct cascade layer, and wiring its exports. Any component create/change MUST then update the docs via skill-contribute-docs AND the component's Figma generation contract (its *.figma.contract.ts); a contract is required for every visual component, whether or not a Figma option was chosen. Brand-agnostic, so it travels into scaffolded projects unchanged.

**Canonical source:** `.agents/skills/skill-contribute-component/SKILL.md`. Claude Code uses `.claude/skills/skill-contribute-component/`; other clients use their installed skill paths.
