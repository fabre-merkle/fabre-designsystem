## When to use it

Generate or update your project's WHOLE Figma component library from code, end to end: bootstrap the Figma variables, generate the components, generate the Code Connect templates, and run the fidelity check, in one orchestrated pass. Use when the user wants to "build/update the Figma library", "sync code to Figma", or run the full code→Figma flow rather than a single step. A thin orchestrator over skill-figma-generate and skill-figma-fidelity-check. Renamed into scaffolded projects as @\<dsname>/skill-figma-library.
