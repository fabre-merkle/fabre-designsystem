## When to use it

Generate a project's Figma component library FROM its code components (the @workspace/ui package), bound to the project's Tokens Studio variables. Produces real, themed, self-documented Figma components — one per page. Use when the user wants to create/update Figma components from code, build a Figma library, or keep design in sync with code. Installs to .claude/skills/ (read natively by the agent).

**Canonical source:** `.agents/skills/skill-figma-generate/SKILL.md`. Claude Code uses `.claude/skills/skill-figma-generate/`; other clients use their installed skill paths.
