## When to use it

This skill should be used when authoring or documenting a UI component, or making any change to the project docs site — documenting a component, writing guidelines/conceptual pages, or curating resource links. It defines universal requirements for every doc contribution plus per-kind specifics (the component section is filled out). Invoked by skill-contribute-component after any component create/change, and usable standalone. Component docs stay in sync with the component and its Figma generation contract. Brand-agnostic, so it travels into scaffolded projects unchanged.

**Canonical source:** `.agents/skills/skill-contribute-docs/SKILL.md`. Claude Code uses `.claude/skills/skill-contribute-docs/`; other clients use their installed skill paths.
