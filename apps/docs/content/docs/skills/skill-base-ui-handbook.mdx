## When to use it

This skill should be consulted whenever authoring or documenting a component built on Base UI v1.9 — it distills the five Base UI handbook pages (composition, customization/styling, animation, forms, TypeScript) into durable, brand-agnostic rules with canonical links. Required reading from skill-contribute-component and skill-contribute-docs; brand-agnostic so it travels into scaffolded projects unchanged.

**Canonical source:** `.agents/skills/skill-base-ui-handbook/SKILL.md`. Claude Code uses `.claude/skills/skill-base-ui-handbook/`; other clients use their installed skill paths.
