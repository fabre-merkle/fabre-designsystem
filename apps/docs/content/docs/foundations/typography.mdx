## Typeface choices

Typefaces carry a product's character and affect how comfortably people read. Make these
choices for the brand and carry them through a small set of text roles rather than choosing
fonts screen by screen. Roles may share a family or use distinct ones: each choice should
have a reason, such as expression for display text, legibility for reading or clear character
shapes for code. Support the languages the product needs.
{/* topic:end typeface-rationale */}

## Hierarchy

Choose a treatment for the job the text does, not for the largest size that fits.

- **Display:** short focal text that sets the tone.
- **Headline:** titles that structure pages, sections and containers.
- **Eyebrow:** a short label providing context above a heading.
- **Paragraph:** reading text, introductions, supporting details and metadata.
- **Control:** labels in interactive elements.
- **Code:** technical content that benefits from fixed-width characters.
- **Link and legal:** navigable text and short supporting notices.

Visual hierarchy and document structure are related but separate. A display treatment does
not itself make text a top-level heading, and an eyebrow does not start a new section.
{/* topic:end type-hierarchy */}

{/* topic:start typography-usage */}
## Usage

Treat each text style as a complete decision: family, size, weight, line height and spacing
work together. Match density to context: a control-heavy interface can favour compact text,
while editorial content can be more generous. Keep text scannable and readable, and allow it
to reflow when zoomed or translated.
{/* topic:end typography-usage */}
