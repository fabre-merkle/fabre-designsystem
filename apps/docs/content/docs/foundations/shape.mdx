## Shape language

Use a consistent shape language so controls and surfaces feel related. Reserve distinctive
shapes for a deliberate purpose rather than changing corners from one component to the next.
{/* topic:end shape-language */}

{/* topic:start radius-intent */}
## What corner choices express

Choose corner treatment in relation to an element's size and purpose. Keep nested shapes
visually coherent, and preserve the same character across related controls and surfaces.
{/* topic:end radius-intent */}
