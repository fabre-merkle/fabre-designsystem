## Grid approach

Use a consistent alignment structure to make relationships between regions clear. Keep
related content together and give the main task a clear place in the page hierarchy.
{/* topic:end layout-grid */}

{/* topic:start layout-responsive */}
## Responsive principles

Let layouts adapt to the available space instead of scaling a desktop composition down
unchanged. Preserve reading order, reachable controls and meaningful content at narrow widths,
large text sizes and high zoom.
{/* topic:end layout-responsive */}

{/* topic:start spacing-rhythm */}
## Spacing rhythm

Use a consistent rhythm for gaps, padding and separation. Smaller gaps can connect related
elements; larger gaps can distinguish groups. Choose space for the relationship it needs to
express, rather than inventing a different distance on every screen.
{/* topic:end spacing-rhythm */}

The same underlying rhythm can connect nearby elements and separate larger regions.
