{/* topic:start icon-style */}
## Icon style

Choose an icon style with consistent visual weight, proportions and detail. Icons should
feel like a family while remaining recognisable at the sizes used in the interface.
{/* topic:end icon-style */}

{/* topic:start icon-usage */}
## Icon usage

Use icons to reinforce an action or meaning, not as a substitute for clarity. Pair unfamiliar
icons with a text label and avoid using the same symbol for unrelated actions.
{/* topic:end icon-usage */}

{/* topic:start imagery */}
## Photography and illustration

Select imagery that supports the content and feels coherent in subject, treatment and tone.
Keep essential information available as text rather than embedding it only in an image.
{/* topic:end imagery */}

{/* topic:start logo-usage */}
## Logo usage

Use approved logo assets without redrawing or distorting them. Preserve enough surrounding
space for recognition and choose a version suitable for its background.
{/* topic:end logo-usage */}
