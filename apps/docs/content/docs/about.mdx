{/* topic:start about-purpose */}
This page records the tools and standards used by this project and the role each plays.
The project owns this baseline documentation. Dependency versions are read from the project
at each documentation build, not frozen when this page is created.

**Resolved** means installed package metadata; **Declared** means a dependency declaration
or package-manager pin, not a verified installation. Missing metadata is shown as **Unavailable**.
Hosted services and standards do not have a project-installed package version.
