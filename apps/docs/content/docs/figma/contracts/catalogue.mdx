The compiler writes a flat summary of every contract to `.agents/component-catalogue.json` in the same
run that writes `.agents/figma-generation-contract.json`. It lists each component's axes with their
values and defaults, its slots and what fills them, its part tree and the components it composes, so an
agent can answer which components exist and what can go in each slot. Run `bun run figma:contract` to
regenerate it and commit the result; `bun run figma:contract:check` fails when it is stale. Never edit
it by hand.

Guidance does not come from the contracts. Write it in `.agents/component-guidance.json`, keyed by
component slug, and the compiler merges it into the catalogue. Every field is optional, and the compiler
refuses an entry or a link that names a component with no contract.

```json
{
  "version": 1,
  "components": {
    "tooltip": {
      "when": "Short, non-essential hints.",
      "avoidWhen": "The content is interactive.",
      "alternatives": ["popover"]
    }
  }
}
```


## ComponentCatalogue

A flat summary of every compiled contract, generated by the compiler and never edited by hand.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `artifact` | `"component-catalogue"` | yes | Identifies the document. |
| `version` | `1` | yes | The catalogue format version. |
| `components` | `object[]` | yes | Every contracted component, sorted by slug. |
| `components[].slug` | `string` | yes | A component slug: lowercase letters, digits and hyphens. |
| `components[].name` | `string` | yes | The component's display name. |
| `components[].description` | `string` |  | One sentence on what the component is. |
| `components[].hash` | `string` | yes | Fingerprint of the normalized contract. Two catalogues with the same hash describe the same contract. |
| `components[].partOf` | `string` |  | Set when this is a part of another component (a label, a legend): that component's slug. |
| `components[].rootPart` | `string` | yes | The part the component's root is drawn as. |
| `components[].parts` | `string[]` | yes | Every declared part. |
| `components[].axes` | `object[]` | yes | The design axes, in the order the contract declares them. |
| `components[].axes[].prop` | `string` | yes | The component prop that carries the axis. |
| `components[].axes[].values` | `string[]` | yes | Every value the axis can take, as declared by the component. |
| `components[].axes[].default` | `string` | yes | The value used when the prop is omitted. |
| `components[].axes[].foldedValues` | `Record<string, Record<string, string>>` |  | Values the code accepts that are not axis values of their own: each maps to the axis values it stands for (for example a button's icon-only sizes). |
| `components[].slots` | `object[]` | yes | The content slots, in the order the contract declares them. |
| `components[].slots[].name` | `string` | yes | The slot's name. |
| `components[].slots[].part` | `string` | yes | The part that renders the slot's content. |
| `components[].slots[].required` | `true` |  | Present when the slot must be filled. |
| `components[].slots[].codeProp` | `string` |  | The prop that receives the content in code, when it is not named after the slot. |
| `components[].slots[].accepts` | `"text" \| "icon" \| "image" \| "component" \| "children" \| "content"` | yes | What fills the slot: `text`, `icon` or `image` for a leaf part of that kind; `component` when its default content is an instance of another component (see `composedChild`); `children` for a region that holds arbitrary content; `content` for any other frame. |
| `components[].slots[].composedChild` | `object` |  | Set when the slot's default content is an instance of another component. |
| `components[].slots[].composedChild.component` | `string` | yes | The component whose instance fills the slot by default. |
| `components[].slots[].composedChild.variantKey` | `Record<string, string>` |  | The axis values of that default instance. |
| `components[].slots[].composedChild.variantKeyFromAxes` | `Record<string, string>` |  | Axes of that instance that follow the parent's variant, as `{ childAxis: parentAxis }`. |
| `components[].properties` | `object[]` |  | The component properties (text, boolean, instance swap), in the order the contract declares them. Absent when the component has none. |
| `components[].properties[].name` | `string` | yes | The Figma property name. |
| `components[].properties[].type` | `"text" \| "boolean" \| "instanceSwap"` | yes | `text` sets the characters of a text part, `boolean` shows or hides a part, `instanceSwap` swaps an icon. |
| `components[].properties[].part` | `string` | yes | The part the property is bound to. |
| `components[].properties[].codeProp` | `string` |  | The prop that carries the value in code, when it has one. |
| `components[].split` | `object` |  | Set when the component generates one component set per value of an axis, instead of one set holding every variant. |
| `components[].split.axis` | `string \| string[]` | yes | The axis whose values each become one set, or the axes whose value combinations each become one. |
| `components[].capReason` | `string` |  | The contract's written reason for a component set to hold more than the 30 variants Figma's library guidance allows. |
| `components[].buildingBlocks` | `object[]` |  | The component's Building Blocks, in the order the contract declares them. |
| `components[].buildingBlocks[].part` | `string` | yes | The part the block is generated from. |
| `components[].buildingBlocks[].name` | `string` | yes | The block's hidden set in Figma, `.Building Blocks/<Component>/<Part>`. |
| `components[].buildingBlocks[].axes` | `string[]` | yes | The block's own axes: its states. |
| `components[].buildingBlocks[].split` | `object` |  | Set when the block generates one hidden set per value of its axes; each set's name puts the value before the label (`.Building Blocks/<Component>/<Value> <Part>`). |
| `components[].buildingBlocks[].split.axis` | `string \| string[]` | yes | The block axis whose values each become one hidden set, or the axes whose value combinations each become one. |
| `components[].anatomy` | `CatalogueAnatomyNode` |  | The part tree. |
| `components[].guidance` | `object` |  | Authored guidance from the sidecar, when the component has an entry. |
| `components[].guidance.when` | `string` |  | When to reach for this component, in one or two sentences. |
| `components[].guidance.avoidWhen` | `string` |  | When another component or approach is the better choice. |
| `components[].guidance.pairsWith` | `string[]` |  | Components that are commonly used together with this one. |
| `components[].guidance.deprecated` | `string` |  | Present when the component is deprecated; the text says why and what to do instead. |
| `components[].guidance.alternatives` | `string[]` |  | Components to use instead of this one, or alongside it as options. |
| `composition` | `object[]` | yes | Which components compose which, sorted by parent, slot, then child. |
| `composition[].parent` | `string` | yes | The component that composes the other. |
| `composition[].slot` | `string` | yes | The parent's slot that holds the child. |
| `composition[].child` | `string` | yes | The composed component. |


## CatalogueAnatomyNode

One part in the component's part tree.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `part` | `string` | yes | The part name. |
| `kind` | `"frame" \| "text" \| "icon" \| "rectangle" \| "ellipse" \| "image"` | yes | What the part is drawn as. |
| `layout` | `"horizontal" \| "vertical" \| "overlay"` |  | How the part lays out its children. |
| `slots` | `string[]` |  | The slots this part renders. |
| `children` | `CatalogueAnatomyNode[]` |  | Child parts, in order. |


## ComponentGuidance

Authored guidance merged into the component catalogue. The compiler reads it from .agents/component-guidance.json when the file exists.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `version` | `1` | yes | The guidance file format version. |
| `components` | `Record<string, object>` | yes | Guidance keyed by component slug. Components without an entry have none. |
| `components[key].when` | `string` |  | When to reach for this component, in one or two sentences. |
| `components[key].avoidWhen` | `string` |  | When another component or approach is the better choice. |
| `components[key].pairsWith` | `string[]` |  | Components that are commonly used together with this one. |
| `components[key].deprecated` | `string` |  | Present when the component is deprecated; the text says why and what to do instead. |
| `components[key].alternatives` | `string[]` |  | Components to use instead of this one, or alongside it as options. |
