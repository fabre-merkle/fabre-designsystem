This page lists the fields you can write in a `<component>.figma.contract.ts` file. It is generated
from `packages/contracts/figma-contract.schema.json`, the JSON Schema that the schema in
`packages/contracts` produces, so it shows this project's schema, including any change you have made
to it.

Nested fields appear under their parent with a dotted path: `[]` marks an array item and `[key]`
marks a record key. The schema checks the shape of each field only. Rules that relate fields to each
other or to the component source are enforced by the compiler, so a contract can pass the schema and
still be refused. Those refusals are listed in the [code reference](/docs/figma/contracts/codes).

## Figma generation contract

An authored Figma generation contract: how one component's parts, axes and documented examples become a Figma component set and documentation page.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `schemaVersion` | `1` | yes | Authored contract schema version. Embedded verbatim in the compiled artifact. |
| `slug` | `string` | yes | The component directory name, e.g. `toggle-group`. |
| `componentName` | `string` | yes | Display name, e.g. `ToggleGroup`. |
| `rootPart` | `string` | yes | The `data-ui` part at the root of the anatomy. |
| `source` | `object` |  | Build this contract from another component's source: `rootPart` is one of that component's parts, which becomes its own Figma component. The registry item, description and category come from the source component. |
| `source.slug` | `string` | yes | The component whose folder holds the `.tsx` and `.css`, e.g. `field`. |
| `parts` | `string[]` | yes | Every `data-ui` part the contract declares. |
| `anatomy` | `FigmaContractAnatomyNode` |  | Explicit parent/child node tree rooted at `rootPart`. |
| `slots` | `object[]` |  | Consumer-fillable content. |
| `slots[].name` | `string` | yes | Stable name documentation examples use to provide content. |
| `slots[].part` | `string` | yes | The declared part that renders this content. |
| `slots[].required` | `boolean` |  | Every documentation example must supply this slot. |
| `slots[].codeProp` | `string` |  | The component prop that receives this slot's content in code, when its name differs from the slot's (a `label` slot is the component's `children`). Omit it when the prop has the slot's own name. |
| `slots[].composedChild` | `object` |  | This slot's default content is an instance of another contracted component. Text an example or item supplies for this slot is set on that instance's text, which needs the child to have exactly one text slot; the instance stays linked to the child. |
| `slots[].composedChild.component` | `string` | yes | The other component's contract `slug`. |
| `slots[].composedChild.variantKey` | `Record<string, string>` |  | Which of the child's variants is the default instance. Omit to use the child's own axis defaults. May name only the axes that differ; each missing axis takes the child's default, unless `variantKeyFromAxes` maps it. |
| `slots[].composedChild.variantKeyFromAxes` | `Record<string, string>` |  | Axes of the child that follow the parent's variant, as `{ childAxis: parentAxis }`: in each variant of the parent, the instance takes the child's value for the axis that the parent's variant has. Every value of the parent axis must be a value of the child axis. A mapped axis takes the parent's value over both `variantKey` and the child's default. In a slot inside a Building Block, the parent axis must be one of the block's axes. |
| `slots[].defaultContent` | `"anatomy"` |  | The region accepts arbitrary children and its default content is the anatomy subtree beneath the frame part that renders this slot. That frame is the slot (a native slot where available, otherwise a plain frame holding the same children). Not combinable with `composedChild`. |
| `slots[].stretch` | `boolean` |  | The slot's frame fills its parent's cross axis, as the CSS content region does. |
| `properties` | `unknown[]` |  | Component properties (text, boolean, instance swap) for what is not a visual difference: editable text, a part that shows or hides, a swappable icon. A visual difference stays an axis; arbitrary children stay a slot. |
| `runtimeValues` | `object[]` |  | Runtime-measured values, declared per documentation example. |
| `runtimeValues[].name` | `string` | yes | Stable name used by `examples[].runtimeValues` and `valueOf.runtimeValue`. |
| `runtimeValues[].part` | `string` | yes | The declared part this value places or sizes. |
| `runtimeValues[].measures` | `"length" \| "travel"` | yes | `length`: percent of the parent's length. `travel`: percent of the parent's free space along its main axis. |
| `runtimeValues[].replaces` | `string[]` | yes | Runtime CSS custom properties this declaration stands in for (may be empty). |
| `runtimeValues[].reason` | `string` | yes | Why the value is measured at runtime and what the representative values show. |
| `axes` | `object[]` |  | Variant axes, in Figma property order. Omitted axes the component source declares are filled in by the compiler; declare design-only axes and curation only. |
| `axes[].prop` | `string` | yes | Prop name as it appears in the component API, e.g. `variant`, `size`. |
| `axes[].values` | `string[]` |  | The axis values, in the order Figma lists them. Required for a design-only axis. For an axis the component source declares, omit it to use the source values, or curate them (a subset or reordering). |
| `axes[].default` | `string` |  | The value used where an example or child omits this axis. Required for a design-only axis; for a source axis it defaults to the source default. |
| `axes[].attribute` | `string` |  | The DOM/CSS attribute that expresses this axis, conventionally `data-<prop>`. Required for a design-only axis; a source axis takes its source attribute. |
| `axes[].valueSelectors` | `Record<string, string \| null>` |  | Per-value CSS selector for values not expressed as `[attribute="value"]`. `null` adds no attribute constraint (the base case). |
| `axes[].partValueSelectors` | `Record<string, Record<string, string \| null>>` |  | Per-part `valueSelectors`, keyed by `data-ui` part name, for a part whose own attribute value differs from the axis value it renders under. |
| `axes[].codeProps` | `Record<string, object>` |  | Code props this axis stands for, keyed by axis value, for a design-only axis whose values group code props. For example `content: { "icon-only": { prop: "iconOnly", value: true } }`. A value with no entry sets nothing. Each key must be one of the axis values. |
| `axes[].codeProps[key].prop` | `string` | yes | The component prop to set. |
| `axes[].codeProps[key].value` | `string \| boolean` | yes | The value to give it: a string the prop accepts, or a boolean. |
| `axes[].foldedValues` | `Record<string, Record<string, string>>` |  | Source values this axis omits from `values`, each mapped to the other axes (prop to value) it folds into, e.g. `size` value `icon-sm` folds into `content: icon-only` with `size: sm`. Recorded for consumers; the variant matrix is built from `values` only. |
| `axes[].attributeOmittedWhenNull` | `boolean` |  | The runtime omits `attribute` entirely for the value whose `valueSelectors` entry is `null`, so valueless `[attribute]` selectors can be evaluated per cell. |
| `split` | `object` |  | Splits the output into one component set per value of a primary axis, or per combination of values of several axes, all generated from this one contract, so a set stays within the 30 variants Figma allows. |
| `split.axis` | `string \| string[]` | yes | The axis whose values each become one component set, or a list of two or more axes whose value combinations each become one (the cartesian product, first axis outermost). A split axis is no longer a variant property inside the sets: each set is named for its values, and Code Connect maps each to the same component with those values as fixed props. |
| `shapes` | `object[]` |  | Kinds of the component generated as sets of their own, such as an icon-only button. Together they say which combinations of axis values exist. |
| `shapes[].name` | `string` |  | The shape's name, written into each set's name (`Primary Filled Icon Button`). At most one shape has none: the component's ordinary sets. |
| `shapes[].values` | `Record<string, string[]>` | yes | The values the shape holds, per axis. An axis not named holds every value; one listed with a single value is fixed in the shape's sets. |
| `shapes[].split` | `object` |  | Splits the output into one component set per value of a primary axis, or per combination of values of several axes, all generated from this one contract, so a set stays within the 30 variants Figma allows. |
| `shapes[].split.axis` | `string \| string[]` | yes | The axis whose values each become one component set, or a list of two or more axes whose value combinations each become one (the cartesian product, first axis outermost). A split axis is no longer a variant property inside the sets: each set is named for its values, and Code Connect maps each to the same component with those values as fixed props. |
| `focusRing` | `object` |  | Generates a ring layer from the root's `:focus-visible` outline: an overlay part outside the root, stroked with the outline's width and colour tokens, shown by a boolean property that is off by default. |
| `focusRing.property` | `string` |  | The boolean property that shows the ring. Defaults to `focus-visible`. |
| `capReason` | `string` |  | Why a set may hold more than the 30 variants Figma's library guidance allows. Without it, a set over the cap is reported as a warning. The reason shows in the compiler output and the docs. |
| `buildingBlocks` | `object[]` |  | Sub-elements with their own states (a select item, a toggle-group segment), each generated as a hidden `.Building Blocks/<Component>/<Part>` set and nested as an instance in this component. |
| `buildingBlocks[].part` | `string` | yes | The declared part that becomes the block. Not the root part, and named `<component>-<name>`. Its slots and properties belong to the block. |
| `buildingBlocks[].name` | `string` |  | The label in the set's name (`.Building Blocks/<Component>/<name>`). Defaults to the part's name without the component's prefix. |
| `buildingBlocks[].axes` | `object[]` | yes | The block's own variant axes (its states), each complete: `values`, `default` and `attribute`. An entry that names an axis of the parent by `prop` alone (optionally curating its values or default) is that axis. A parent axis of the same name shows the instance in the matching state; otherwise the instance shows the default. |
| `buildingBlocks[].axes[].prop` | `string` | yes | Prop name as it appears in the component API, e.g. `variant`, `size`. |
| `buildingBlocks[].axes[].values` | `string[]` |  | The axis values, in the order Figma lists them. Required for a design-only axis. For an axis the component source declares, omit it to use the source values, or curate them (a subset or reordering). |
| `buildingBlocks[].axes[].default` | `string` |  | The value used where an example or child omits this axis. Required for a design-only axis; for a source axis it defaults to the source default. |
| `buildingBlocks[].axes[].attribute` | `string` |  | The DOM/CSS attribute that expresses this axis, conventionally `data-<prop>`. Required for a design-only axis; a source axis takes its source attribute. |
| `buildingBlocks[].axes[].valueSelectors` | `Record<string, string \| null>` |  | Per-value CSS selector for values not expressed as `[attribute="value"]`. `null` adds no attribute constraint (the base case). |
| `buildingBlocks[].axes[].partValueSelectors` | `Record<string, Record<string, string \| null>>` |  | Per-part `valueSelectors`, keyed by `data-ui` part name, for a part whose own attribute value differs from the axis value it renders under. |
| `buildingBlocks[].axes[].codeProps` | `Record<string, object>` |  | Code props this axis stands for, keyed by axis value, for a design-only axis whose values group code props. For example `content: { "icon-only": { prop: "iconOnly", value: true } }`. A value with no entry sets nothing. Each key must be one of the axis values. |
| `buildingBlocks[].axes[].codeProps[key].prop` | `string` | yes | The component prop to set. |
| `buildingBlocks[].axes[].codeProps[key].value` | `string \| boolean` | yes | The value to give it: a string the prop accepts, or a boolean. |
| `buildingBlocks[].axes[].foldedValues` | `Record<string, Record<string, string>>` |  | Source values this axis omits from `values`, each mapped to the other axes (prop to value) it folds into, e.g. `size` value `icon-sm` folds into `content: icon-only` with `size: sm`. Recorded for consumers; the variant matrix is built from `values` only. |
| `buildingBlocks[].axes[].attributeOmittedWhenNull` | `boolean` |  | The runtime omits `attribute` entirely for the value whose `valueSelectors` entry is `null`, so valueless `[attribute]` selectors can be evaluated per cell. |
| `buildingBlocks[].focusRing` | `object` |  | Generates the block's ring layer from its part's `:focus-visible` outline, as `focusRing` does for a contract's root. |
| `buildingBlocks[].focusRing.property` | `string` |  | The boolean property that shows the ring. Defaults to `focus-visible`. |
| `buildingBlocks[].split` | `object` |  | Splits the block into one hidden set per value, or combination of values, of its own axes (`.Building Blocks/<Component>/<Value> <Label>`), as `split` does for a contract. An instance shows the set that holds its variant. |
| `buildingBlocks[].split.axis` | `string \| string[]` | yes | The axis whose values each become one component set, or a list of two or more axes whose value combinations each become one (the cartesian product, first axis outermost). A split axis is no longer a variant property inside the sets: each set is named for its values, and Code Connect maps each to the same component with those values as fixed props. |
| `documentation` | `object` | yes | The documentation page's examples. |
| `documentation.examples` | `object[]` | yes | Documented examples, in page order. |
| `documentation.examples[].label` | `string` | yes | Caption shown for this example. |
| `documentation.examples[].key` | `Record<string, string>` | yes | The variant cell this example shows, as axis to value. May name only the axes that differ; each missing axis takes the component's default. |
| `documentation.examples[].slots` | `Record<string, string>` |  | Representative content keyed by declared slot name. |
| `documentation.examples[].runtimeValues` | `Record<string, string>` |  | Representative percent (0 to 100) of each declared runtime value. |
| `documentation.coverage` | `"all-axes"` |  | Require the examples to cover every value of every axis. |
| `reactToFigmaNotes` | `string[]` |  | Reviewed differences between the React API and the design-only axes. |
| `literalGeometry` | `object[]` |  | Dimensions CSS states as literals rather than bindable variables. |
| `literalGeometry[].part` | `string` | yes | The declared part. |
| `literalGeometry[].when` | `Record<string, string>` |  | Apply only in variant cells matching every axis. |
| `literalGeometry[].width` | `number` |  |  |
| `literalGeometry[].height` | `number` |  |  |
| `literalGeometry[].fontSize` | `number` |  |  |
| `literalGeometry[].lineHeight` | `number` |  |  |
| `literalGeometry[].lineHeightUnit` | `"pixels" \| "unitless"` |  |  |
| `omittedParts` | `Record<string, string \| object>` |  | Real, CSS-styled parts the contract deliberately does not declare, each with a reviewed reason. |
| `omittedParts[key].kind` | `"window-relative" \| "runtime-position" \| "unrepresentable-state"` | yes | `window-relative`: fixed to the browser window. `runtime-position`: placed at runtime. `unrepresentable-state`: exists only under a state no axis expresses. |
| `omittedParts[key].reason` | `string` | yes | Reviewed justification. |
| `omittedParts[key].via` | `string` |  | For `unrepresentable-state`: the omitted part this one is only reachable through. |

| `viewport.dock.edges` | `Record<string, "top" \| "right" \| "bottom" \| "left">` | yes | Axis value to frame edge. |
| `viewport.corner` | `"top-left" \| "top-right" \| "bottom-left" \| "bottom-right"` |  | Required with `placement: "corner"`. |

## FigmaContractAnatomyNode

One node of the component's Figma node tree.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `part` | `string` | yes | The declared part (a `data-ui` name) this node renders. |
| `synthetic` | `boolean` |  | A contract-only composition role with no `data-ui` source part. |
| `docsLayout` | `object` |  | Gap and alignment for a synthetic container, taken from the documentation markup that composes it. |
| `docsLayout.gap` | `string` |  | A bare `var(--token-name)` reference, bound as the node's item spacing. |
| `docsLayout.justify` | `"start" \| "center" \| "end" \| "space-between"` |  | Main-axis alignment (Figma `primaryAxisAlignItems`). |
| `docsLayout.align` | `"start" \| "center" \| "end" \| "stretch"` |  | Cross-axis alignment (Figma `counterAxisAlignItems`). |
| `docsLayout.source` | `string` | yes | `<docs file path>:<line>` where the documentation markup authors this layout. |
| `kind` | `"frame" \| "text" \| "icon" \| "rectangle" \| "ellipse" \| "image"` | yes | The Figma node this part materializes as. |
| `layout` | `"horizontal" \| "vertical" \| "overlay"` |  | Auto-layout direction of a frame, or `overlay` for children stacked over one another (not flowed). |
| `layoutByAxis` | `object` |  | Layout chosen by a visual axis, when the anatomy differs by (for example) orientation. |
| `layoutByAxis.axis` | `string` | yes | The declared axis whose value selects the entry. |
| `layoutByAxis.values` | `Record<string, "horizontal" \| "vertical" \| "overlay">` | yes | Axis value to resolved value. Unlisted values fall back to the plain field. |
| `overlayCrossAlign` | `"start" \| "center" \| "end" \| "stretch"` |  | Placement within an `overlay` parent on the axis across the parent's long direction. |
| `overlayCrossAlignByAxis` | `object` |  | `overlayCrossAlign` chosen by a visual axis. |
| `overlayCrossAlignByAxis.axis` | `string` | yes | The declared axis whose value selects the entry. |
| `overlayCrossAlignByAxis.values` | `Record<string, "start" \| "center" \| "end" \| "stretch">` | yes | Axis value to resolved value. Unlisted values fall back to the plain field. |
| `removeFromFlow` | `boolean` |  | Exempt this child from its auto-layout parent's flow (Figma absolute positioning). Requires `reason`. |
| `removeFromFlowByAxis` | `object` |  | `removeFromFlow` chosen by a visual axis. Requires `reason`. |
| `removeFromFlowByAxis.axis` | `string` | yes | The declared axis whose value selects the entry. |
| `removeFromFlowByAxis.values` | `Record<string, boolean>` | yes | Axis value to resolved value. Unlisted values fall back to the plain field. |
| `positionAlongMain` | `object` |  | Offset along the parent's main axis: a literal anchor, a value-driven anchor, or an explicit, reported refusal. |
| `positionAlongMain.kind` | `"start" \| "center" \| "end" \| "stretch" \| "valueOf" \| "refused"` | yes | Anchor on one axis of the parent: an edge, the centre, or spanning the parent. |
| `positionAlongMain.slot` | `string` |  | A declared slot whose example text is the value. |
| `positionAlongMain.runtimeValue` | `string` |  | A declared runtime value. |
| `positionAlongMain.jsProperty` | `string` |  | The runtime (JavaScript) property that really positions the part. |
| `positionAlongMainByAxis` | `object` |  | `positionAlongMain` chosen by a visual axis. Requires `reason`. |
| `positionAlongMainByAxis.axis` | `string` | yes | The declared axis whose value selects the entry. |
| `positionAlongMainByAxis.values` | `Record<string, object>` | yes | Axis value to resolved value. Unlisted values fall back to the plain field. |
| `positionAlongMainByAxis.values[key].kind` | `"start" \| "center" \| "end" \| "stretch" \| "valueOf" \| "refused"` | yes | Anchor on one axis of the parent: an edge, the centre, or spanning the parent. |
| `positionAlongMainByAxis.values[key].slot` | `string` |  | A declared slot whose example text is the value. |
| `positionAlongMainByAxis.values[key].runtimeValue` | `string` |  | A declared runtime value. |
| `positionAlongMainByAxis.values[key].jsProperty` | `string` |  | The runtime (JavaScript) property that really positions the part. |
| `sizeAlongMain` | `object` |  | Length along the parent's main axis, value-driven and pinned at the parent's origin. Requires `reason`. |
| `sizeAlongMain.kind` | `"valueOf"` | yes |  |
| `sizeAlongMain.slot` | `string` |  | A declared slot whose example text is the value. |
| `sizeAlongMain.runtimeValue` | `string` |  | A declared runtime value. |
| `reason` | `string` |  | Why placement is declared instead of derived. Required with `removeFromFlow`, `positionAlongMain` and `sizeAlongMain`. |
| `slots` | `string[]` |  | Declared slots whose example content renders in this node. |
| `when` | `Record<string, string \| string[]>` |  | Render only in variant cells matching every axis; an array value matches any of its values. |

| `children` | `FigmaContractAnatomyNode[]` |  | Child nodes, in order. |
