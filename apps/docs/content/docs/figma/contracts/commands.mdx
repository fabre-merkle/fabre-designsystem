This page is generated from `packages/contracts/src/project-compiler/commands.ts`, the module the
`--help` text is built from. Run the commands with `bun run contracts <command>` from the
`packages/contracts` directory. Every command prints each problem as a diagnostic with a stable
code, listed in the [code reference](/docs/figma/contracts/codes).

| Command | Arguments | Flags | What it does |
| --- | --- | --- | --- |
| `contracts compile` | - | `--root <dir>` `--json` | Compile every contract into the artifact and the component catalogue |
| `contracts check` | - | `--root <dir>` `--json` | Fail when the committed artifact or catalogue is stale |
| `contracts validate` | `<slug>` | `--root <dir>` `--json` | Check one contract against the schema and the compiler |
| `contracts list` | - | `--root <dir>` `--json` | List the contracts in the project |
| `contracts explain` | `[slug]` | `--root <dir>` `--json` | Describe one contract: parts, axes, slots and where each axis comes from |
| `contracts new` | `[slug]` | `--root <dir>` `--json` `--force` `--yes` | Write a starter contract pre-filled from the component's code |

## Flags

| Flag | Commands | Meaning |
| --- | --- | --- |
| `--root <dir>` | `compile` `check` `validate` `list` `explain` `new` | The workspace root, instead of searching upward from the current directory. |
| `--json` | `compile` `check` `validate` `list` `explain` `new` | Print one JSON document (code, severity, path, message and remedy for every diagnostic) instead of text. Never prompts. |
| `--force` | `new` | Overwrite an existing contract file. |
| `--yes` | `new` | Answer yes to every question (replace an existing contract) and never prompt. |


## Exit codes

| Exit code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | A contract was refused, or the committed artifact is stale. |
| `2` | Usage error: an unknown command, flag or slug. |
| `3` | A prerequisite is missing; the message names it. |
