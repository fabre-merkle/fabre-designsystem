## Start with a prompt

Open your product project in your coding agent and paste this prompt. Replace the bracketed task with the interface you want to build.

<div data-docs-prompt="">

```text title="Copy this prompt into your agent"
Set up this project to use the design system documented on this site, then build [describe my interface].
Read the project's AGENTS.md and relevant installed skills first.
Check the framework, package manager, dependencies and stylesheet entry point; preserve the project's existing setup.
Read DESIGN.md for the matching brand and theme.
Follow this site's /docs/registry guide to configure @fabre-designsystem in this product's components.json.
Discover the published items in @fabre-designsystem; inspect their requirements and install only what the interface needs.
If the registry is unpublished or an item is unavailable, explain what is missing and stop that installation. Do not substitute another library.
Follow /docs/mcp to connect Docs MCP and Registry MCP at project scope; preserve existing configuration and verify both connections. If unavailable, read /llms.txt and page Markdown.
If I provide a Figma design, follow /docs/figma and confirm access to the intended file before using it.
Reuse installed components and semantic tokens. Preserve accessibility and responsive behaviour.
Show me the first working interface and the changes made; run the affected project checks before handing it back.
```

</div>

Review proposed file changes and any credential or access requests before accepting them.

## Or set up manually

Work in the product repository where you want to build the interface—not a checkout of the documentation site.

<Steps>
<Step>
### Connect the registry

<RelatedPage href="/docs/registry">Add the published namespace, URL and any required project access.</RelatedPage>
Then discover the available items:
```npm
npx shadcn@latest search @fabre-designsystem
```
</Step>
<Step>
### Inspect and install

Replace `<item>` with an exact name returned by registry discovery:

```npm
npx shadcn@latest view @fabre-designsystem/<item>
npx shadcn@latest add @fabre-designsystem/<item>
```

Follow the item's dependency, stylesheet and provider instructions. Review the diff before overwriting local code. If the registry is not published, obtain its URL from the design-system owner before continuing.
</Step>
<Step>
### Connect your agent

<RelatedPage href="/docs/mcp">Install Docs MCP and Registry MCP for your client, then verify both.</RelatedPage>
</Step>
<Step>
### Use a Figma design

<RelatedPage href="/docs/figma">Confirm library access and follow the project's design-to-code guidance.</RelatedPage>
</Step>
<Step>
### Build your first interface
Use the installed component examples and semantic tokens to implement one screen. Run the product's dev script and affected checks; review keyboard use and the narrow-screen layout.
</Step>
</Steps>

<RelatedPage href="/docs/cli">Find CLI commands and the installed design-system scripts.</RelatedPage>
