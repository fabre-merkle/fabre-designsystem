## Installation

`Fieldset` already ships in this project's component library, in the directory chosen when the project
was scaffolded. Import it from the project's namespace:

```tsx
import { Fieldset } from "@workspace/ui/components/fieldset";
```

### Add or update from the design-system registry

This component is already installed in the design-system repository. To use it in another product, install from this design system's own published registry.

<RelatedPage href="/docs/registry">Configure the design-system namespace, published URL and any required credentials.</RelatedPage>

After publication, search for the component and use the exact item name returned by the registry:

```npm
npx shadcn@latest search @fabre-designsystem
npx shadcn@latest add @fabre-designsystem/<item>
```

Replace `<registry>` with this design system's namespace and `<item>` with the published name. If the registry is not published, use the installed source; do not substitute a different library. Review the diff before accepting an overwrite.

## Usage

```tsx
import { Field } from "@workspace/ui/components/field";
import { Fieldset } from "@workspace/ui/components/fieldset";
import { Input } from "@workspace/ui/components/input";

<Fieldset.Root>
  <Fieldset.Legend>Billing contact</Fieldset.Legend>
  <Field.Root name="name">
    <Field.Label>Full name</Field.Label>
    <Field.Control render={<Input />} />
  </Field.Root>
</Fieldset.Root>
```

Wrap a group of related `Field`s in `Fieldset.Root` and give the group an accessible name with `Fieldset.Legend`.

## API Reference

Fieldset adds no props beyond the primitive's. All parts forward to the matching [Base UI Fieldset](https://base-ui.com/react/components/fieldset#api-reference) primitives — `Fieldset.Root`, `Fieldset.Legend` — preserving every prop, event, ARIA attribute, and the polymorphic `render` API.
