## Icons

Icons are children. Put `data-icon="inline-start"` or `data-icon="inline-end"` on the icon beside a label: the icon takes the size from the button (`--ctl-icon`), the gap comes from the button, and the side that carries an icon gives back a little padding. `data-icon` is optional: with none, an icon placed first is a start icon and an icon placed last, after the text, is an end icon, so a bare icon component works. Add `data-icon` to state the side explicitly; it wins where present.

```tsx
<Button><Plus />New project</Button>
<Button>Continue<ArrowRight /></Button>
<Button><Plus data-icon="inline-start" />New project</Button>
<Button size="icon" aria-label="Settings"><Gear /></Button>
```

Any `svg` child, and any child with `data-icon`, is sized by the button. A size class on the icon itself still wins.

### Icon sizes

The `icon-*` sizes make a square icon-only control at the height of the matching size: `icon-xs` is `xs`, `icon-sm` is `sm`, `icon` is `md` and `icon-lg` is `lg`. `size` keeps `xs | sm | md | lg` with `md` as the default, so the icon sizes sit beside them rather than replacing `md` with `default`. An icon-only control has no visible text, so it needs an accessible name from `aria-label`, `aria-labelledby` or visually hidden text. In development it throws without one.
