## Usage

```tsx
import { Dialog } from "@workspace/ui/components/dialog";
import { Button } from "@workspace/ui/components/button";

<Dialog.Root>
  <Dialog.Trigger render={<Button>Open</Button>} />
  <Dialog.Portal>
    <Dialog.Backdrop />
    <Dialog.Popup>
      <Dialog.Header>
        <Dialog.Title>Title</Dialog.Title>
        <Dialog.Description>Description</Dialog.Description>
      </Dialog.Header>
      <Dialog.Footer>
        <Dialog.Close render={<Button variant="secondary" mode="ghost">Close</Button>} />
      </Dialog.Footer>
    </Dialog.Popup>
  </Dialog.Portal>
</Dialog.Root>
```

## API Reference

`Root`, `Trigger`, `Portal`, `Backdrop`, `Popup`, `Title`, `Description` and `Close` forward to the matching [Base UI Dialog](https://base-ui.com/react/components/dialog#api-reference) primitives, preserving every prop, event, ARIA attribute, and the polymorphic `render` API.

`Header` and `Footer` are layout parts with no Base UI counterpart. Each renders a `div`, accepts any `div` prop and the `render` prop, and is optional.

| Part | Renders | Layout |
| --- | --- | --- |
| `Dialog.Header` | `div` | Stacks `Title` over `Description`. |
| `Dialog.Footer` | `div` | A row of actions aligned to the end. Below the small breakpoint the actions stack, in reverse order, so the last action in the markup sits on top. Put the primary action last. |

Nothing adds a corner close button, and the popup scrolls as before.

## Composition

Wrap any element with `render={<YourComponent />}` on `Trigger` and `Close` to use the project's `Button` (or any other element) as the interactive control. Base UI merges props and ref into the rendered element automatically.
