## Installation

`OTPField` already ships in this project's component library, in the directory chosen when the project
was scaffolded. Import it from the project's namespace:

```tsx
import { OTPField } from "@workspace/ui/components/otp-field";
```

### Add or update from the design-system registry

This component is already installed in the design-system repository. To use it in another product, install from this design system's own published registry.

<RelatedPage href="/docs/registry">Configure the design-system namespace, published URL and any required credentials.</RelatedPage>

After publication, search for the component and use the exact item name returned by the registry:

```npm
npx shadcn@latest search @fabre-designsystem
npx shadcn@latest add @fabre-designsystem/<item>
```

Replace `<registry>` with this design system's namespace and `<item>` with the published name. If the registry is not published, use the installed source; do not substitute a different library. Review the diff before accepting an overwrite.

## Usage

```tsx
import { OTPField } from "@workspace/ui/components/otp-field";

<OTPField.Root length={6}>
  <OTPField.Input />
  <OTPField.Input />
  <OTPField.Input />
  <OTPField.Separator />
  <OTPField.Input />
  <OTPField.Input />
  <OTPField.Input />
</OTPField.Root>
```

`OTPField.Root` requires `length`, the total number of slots. Render one `OTPField.Input` per slot; their order is the slot order. `OTPField.Separator` is decorative and groups slots, for example 3 and 3 for a six-digit code. Wrap the field in `Field.Root` (with `invalid`) and a `Field.Label` to name it and drive the error state.

## API Reference

`OTPField` adds no props. Every part forwards to the matching [Base UI OTPField](https://base-ui.com/react/components/otp-field#api-reference) part, preserving every prop, event, ARIA attribute and the `render` API.
