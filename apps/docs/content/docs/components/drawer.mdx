## Usage

```tsx
import { Drawer } from "@workspace/ui/components/drawer";
import { Button } from "@workspace/ui/components/button";

<Drawer.Root>
  <Drawer.Trigger render={<Button>Open drawer</Button>} />
  <Drawer.Portal>
    <Drawer.Backdrop />
    <Drawer.Viewport>
      <Drawer.Popup>
        <Drawer.Title>Account settings</Drawer.Title>
        <Drawer.Description>Update your profile and preferences.</Drawer.Description>
        <Drawer.Close render={<Button>Save changes</Button>} />
      </Drawer.Popup>
    </Drawer.Viewport>
  </Drawer.Portal>
</Drawer.Root>
```

## API Reference

Drawer adds no props beyond the primitive's. All parts forward to the matching [Base UI Drawer](https://base-ui.com/react/components/drawer#api-reference) primitives — `Root`, `Provider`, `Trigger`, `Portal`, `Backdrop`, `Popup`, `Viewport`, `Content`, `Title`, `Description`, `Close`, `SwipeArea`, `Indent`, `IndentBackground` — preserving every prop, event, ARIA attribute, and the polymorphic `render` API. `Drawer.createHandle` is re-exported from the Base UI primitive for detached-trigger control.

`Root` defaults `swipeDirection` to `"down"` (bottom-sheet). Set `swipeDirection="right" | "left" | "up"` to anchor the drawer to a different edge — The component CSS recognises `data-side` on the popup and applies the matching edge anchoring and enter/exit transform automatically.

## When to use

Use `Drawer` for a panel that should slide in from a viewport edge with optional swipe-to-dismiss and snap points — mobile sheets, side filter panels, multi-step task surfaces. The drawer is modal by default (`modal={true}`) and traps focus; pass `modal="trap-focus"` or `modal={false}` to relax those behaviors. For centred modal confirmations or focused tasks use `Dialog`; for irreversible confirmations use `AlertDialog`; for click-anchored contextual menus use `Popover`.

## Composition

Variants are styling-only and never alter Base UI behavior. Focus management, ARIA roles, scroll lock, the swipe gesture, and snap-point logic come from the Base UI primitive. Edge anchoring is selected via `Root`'s `swipeDirection` prop and applied to the popup through `data-side`. The default (`"down"`) gives a full-width bottom sheet; `"right"` / `"left"` produce a side panel capped at 420px; `"up"` produces a top sheet.

For nested or detached triggers, use `Drawer.createHandle()` and pass the handle to `Root` (and to any standalone `Trigger`) — see Base UI's documentation for the imperative API.
