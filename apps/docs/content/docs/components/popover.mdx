## Installation

`Popover` already ships in this project's component library, in the directory chosen when the project
was scaffolded. Import it from the project's namespace:

```tsx
import { Popover } from "@workspace/ui/components/popover";
```

### Add or update from the design-system registry

This component is already installed in the design-system repository. To use it in another product, install from this design system's own published registry.

<RelatedPage href="/docs/registry">Configure the design-system namespace, published URL and any required credentials.</RelatedPage>

After publication, search for the component and use the exact item name returned by the registry:

```npm
npx shadcn@latest search @fabre-designsystem
npx shadcn@latest add @fabre-designsystem/<item>
```

Replace `<registry>` with this design system's namespace and `<item>` with the published name. If the registry is not published, use the installed source; do not substitute a different library. Review the diff before accepting an overwrite.

## Usage

```tsx
import { Popover } from "@workspace/ui/components/popover";
import { Button } from "@workspace/ui/components/button";

<Popover.Root>
  <Popover.Trigger render={<Button>Open</Button>} />
  <Popover.Portal>
    <Popover.Positioner>
      <Popover.Popup>
        <Popover.Title>Title</Popover.Title>
        <Popover.Description>Description</Popover.Description>
      </Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>
```

## API Reference

Popover adds no props. All parts forward to the matching [Base UI Popover](https://base-ui.com/react/components/popover#api-reference) primitives — `Root`, `Trigger`, `Portal`, `Backdrop`, `Positioner`, `Popup`, `Arrow`, `Title`, `Description`, `Close` — preserving every prop, event, ARIA attribute, and the polymorphic `render` API.

`Positioner` defaults `sideOffset` to `8` for visual separation from the trigger; pass any positioning prop to override.

## When to use

Use `Popover` for non-modal contextual content tied to a trigger — info panels, lightweight forms, inline controls. For required confirmations use `AlertDialog`; for focused tasks that should block the rest of the UI use `Dialog`; for short hover-only hints use `Tooltip`.

## Composition

Wrap any element with `render={<YourComponent />}` on `Trigger` and `Close` to use the project's `Button` (or any other element) as the interactive control. Base UI merges props and ref into the rendered element automatically.
