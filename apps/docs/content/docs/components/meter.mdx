## Installation

`Meter` already ships in this project's component library, in the directory chosen when the project
was scaffolded. Import it from the project's namespace:

```tsx
import { Meter } from "@workspace/ui/components/meter";
```

### Add or update from the design-system registry

This component is already installed in the design-system repository. To use it in another product, install from this design system's own published registry.

<RelatedPage href="/docs/registry">Configure the design-system namespace, published URL and any required credentials.</RelatedPage>

After publication, search for the component and use the exact item name returned by the registry:

```npm
npx shadcn@latest search @fabre-designsystem
npx shadcn@latest add @fabre-designsystem/<item>
```

Replace `<registry>` with this design system's namespace and `<item>` with the published name. If the registry is not published, use the installed source; do not substitute a different library. Review the diff before accepting an overwrite.

## Usage

```tsx
import { Meter } from "@workspace/ui/components/meter";

<Meter.Root value={64}>
  <Meter.Label>Storage used</Meter.Label>
  <Meter.Value />
  <Meter.Track>
    <Meter.Indicator />
  </Meter.Track>
</Meter.Root>
```

## API Reference

`Meter.Root` adds two props (`size`, `tone`) on top of [Base UI Meter.Root](https://base-ui.com/react/components/meter#api-reference); every other part forwards its primitive props untouched. Props below are all on `Meter.Root`.

<AutoTypeTable path="meter/meter.tsx" name="DocsRootProps" type="RootProps" />

`Meter.Value` accepts a function child `(formattedValue: string, value: number) => ReactNode` if you need to render the value differently from the default formatter.

## When to use

Use `Meter` for a static measurement against a known range — disk usage, battery level, score, capacity. For an ongoing operation with progress over time, use `Progress` instead.
