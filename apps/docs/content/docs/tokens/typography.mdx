Composite styles keep family, size, weight, line height and letter spacing together. Use a
complete style, or its matching properties, rather than mixing parts from unrelated roles.
Values respond to the active brand and viewport.

<TokenReference category="typography" />

## Choosing a style

Display styles support short focal phrases; headline styles establish page and section
hierarchy. Paragraph styles support reading, with smaller sizes for compact content and
metadata. Use control styles for control labels, code styles for code and data, and an
eyebrow for a short context label above a heading.

Match a control's text style to its size. Keep links recognisable as links, let text reflow
and allow user text-spacing overrides without losing content.
