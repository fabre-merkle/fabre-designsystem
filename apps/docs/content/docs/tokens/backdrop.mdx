Each semantic backdrop combines a blur value with a saturation value. The preview uses the
active project's values so the effect can be compared over the same underlying content.

## Applying backdrop

Use a backdrop when the content behind a surface should remain perceptible but less
distracting. Provide an opaque or otherwise legible fallback when the effect is unavailable,
and verify foreground contrast over varied content.
