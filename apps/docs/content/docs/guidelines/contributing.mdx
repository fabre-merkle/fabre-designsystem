---
title: Contributing
description: A practical starting point for changing the design system.
---

<Steps>

<Step>

### Describe the problem

Explain the problem and who it affects. Agree on the intended change before implementing it.

</Step>

<Step>

### Make the change

Use the project's existing patterns and provide documentation or an example that explains the
result. Preserve the owning page and retained topic markers when updating guidance.

</Step>

<Step>

### Review and verify

Check accessibility, run the relevant tests and build, and document breaking changes or
migrations. Follow the project's review and release process.

</Step>

</Steps>
